# I19 · Attachments

**You will learn:** to link video, audio and any other file.

An attachment is a Markdown link with a symbol in front that says what it is: `[▶ name](path)` for video, `[♪ name](path)` for audio and `[📎 name](path)` for everything else. The file is copied into `assets/` just like images, so the note travels with its attachments and doesn't depend on the folder they came from.
