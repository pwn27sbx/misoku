# I30 · Intermediate challenge

**You will learn:** to bring the whole route together in a note you would really use.

This challenge checks nothing: it is about writing a trip plan with the forms you have already practised. If something doesn't work out, go back to the lesson that teaches it; the whole route is behind you.

## Your turn

1. Create the note `Trip to the coast` with headings, a list and two tags.
2. Add a three-column table: day, plan and cost.
3. Create the note `Budget`, mark a paragraph with `^total` and link that block from `Trip to the coast`.
4. Add a board to the note with a card in `Pending`.
5. Go over everything in the reading view with `space p`.
