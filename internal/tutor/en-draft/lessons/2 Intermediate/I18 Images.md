# I18 · Images

**You will learn:** to add an image of your own and to paste one from the clipboard.

Have an image on your computer at hand, outside the vault. `/Image` copies the file into the `assets/` folder next to the note and leaves a line `![name](path)`; if the file is already inside the vault, it doesn't copy it, it only links it. `/Paste image` (or `space i`) does the same with an image from the clipboard. The preview draws the image if your terminal can.

## Your turn

1. Insert `/Image`, pick an image from outside the vault and look at the line it leaves.
2. Copy an image to the clipboard and use `/Paste image` (or `space i`).
3. Look at the image drawn in the preview.
4. Check next to the note that the file was copied into `assets/`.
