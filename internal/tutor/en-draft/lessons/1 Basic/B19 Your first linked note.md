# B19 · Your first linked note

**You will learn:** to write a link with the inline list that `[[` opens, and to close it with `Esc` so you can write the link by hand.

Typing `[[` opens a list of notes below the cursor; you filter by typing, choose with the arrows, and `Enter` completes the link. `Esc` closes the list without completing anything and keeps the `[[` you had typed: that way you can finish the link by hand. A link only stores the note's name; if the note doesn't exist, it is created when you open it from the link. The list appears by itself as you type and the focus stays on the text: `Esc` only closes the list.

## Your turn

1. Type `[[`, type `Weekly shopping` and press `Enter`: the list completes the link.
2. On another line, type `[[`, close the list with `Esc` and finish `[[Market]]` by hand.
