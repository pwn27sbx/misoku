# B14 · Lists

**You will learn:** bullets, numbered lists, tasks, and nesting an item with `Tab`.

`- ` starts a bullet, `1. ` a numbered list and `- [ ] ` a task with a checkbox; the `/` menu writes all three for you. If you type `- []` and then a space, it completes itself to `- [ ] `. `Tab` on an item nests it one level and `Shift+Tab` brings it back. In the preview, the list shows its bullets, numbers and checkboxes. Each item goes on its own line and the menu leaves the cursor ready for you to type the text.

## Your turn

1. Write a bullet with `/Bulleted list` (or `- `).
2. Write a numbered list with `/Numbered list` (or `1. `).
3. Write a task with `/To-do list` (or `- [ ] `).
4. With the cursor on the bullet item, press `Tab` and then `Shift+Tab`.
