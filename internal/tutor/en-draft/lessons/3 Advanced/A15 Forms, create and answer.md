# A15 · Forms: create and answer

**You will learn:** to insert a form into a note and to answer it from the preview, with the answers written inside the block itself.

A form is a fenced block of type `form`. It has a `title:`, an optional `description:` and one line per question, each starting with `?`. Answering is not a separate dialog: the preview draws the questions as a form and, when you answer, writes the answer into the block, under its question, as a line that starts with `=`.

That means the answers are text of the note: they are saved, synced and can be read or searched like any other line. And the question's type decides the gesture: a text one opens a field, a date one opens the calendar, a choice one is answered with a click.

The `/` menu has the `Form` item, which already brings the title and two example questions. From there on, it is just typing.
