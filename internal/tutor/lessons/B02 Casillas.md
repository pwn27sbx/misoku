# Nivel 2 · Casillas

**Vas a aprender:** listas y tareas que se marcan.

Una lista empieza cada línea con `- `. Una tarea es una lista con casilla: `- [ ] comprar pan`. Hecha, lleva una x: `- [x] comprar pan`.

Ojo: `- [ ]` lleva espacio entre los corchetes; `- []` no es una tarea.

Para marcar o desmarcar una casilla sin escribir la x: pon el cursor en la línea y pulsa `Enter` en modo NORMAL. También puedes crearla con el menú `/` → `To-do list`.
