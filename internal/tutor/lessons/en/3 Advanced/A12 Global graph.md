# A12 · Global graph

**You will learn:** to see the whole vault at once and to start a note that does not exist yet from the map.

`space G`, `:graph all` or the `g` key on the home screen open the global graph. Here there is no note in the centre: there are constellations, one per top-level folder, and each note is a node with its links.

A note that does not exist but is linked does not disappear: it is drawn hollow, with its name. It is an idea written down that has no note yet, and the map shows it to you so it does not get lost.

`Enter` on a hollow node creates the note with that name, exactly as if you opened it from a link. That way the graph is for planning: you write the links of what you want to have and then fill in the gaps.

## Your turn

1. Press `space G` (or `:graph all`, or `g` on the home screen) and see the whole vault by folders.
2. Write `[[Backpack]]` in a note, open the global graph, find the hollow node with that name and press `Enter` to start the note.
