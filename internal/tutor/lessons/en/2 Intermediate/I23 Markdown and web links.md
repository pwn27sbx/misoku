# I23 · Markdown and web links

**You will learn:** to link notes and web pages without the double-bracket syntax.

Not every link is a `[[…]]`. Classic Markdown writes the text in square brackets and the path in parentheses: `[my note](Trip.md)`. That link points to a file, so the path has to exist. For the web there are two forms: `[documentation](https://example.com)` and `<https://example.com>`, the second when what you read is the address itself. With the cursor on a link, `space o ]` jumps to the next one and `space o [` to the previous one.
