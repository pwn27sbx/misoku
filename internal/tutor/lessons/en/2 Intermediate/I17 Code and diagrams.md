# I17 · Code and diagrams

**You will learn:** to keep code untouched by Markdown and to draw a flow.

A code block is a fence with no language: everything inside stays exactly as it is, with no bold or lists. A flowchart is a `flow` fence with arrow lines: `Start --> End` joins two boxes, and the preview draws it with boxes and arrows, with no external tools. They are two sides of the same thing: text the preview understands in a different way.
