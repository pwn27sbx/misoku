# I06 · Pages and sub-notes

**You will learn:** to create a child note from the text and from the explorer.

A sub-note is not just any note: it lives in a folder named after its parent note. If `Trip` has the sub-notes `Beach packing` and `Day 1`, you find them in `Trip/`, and if you rename or move the parent, the folder follows it. There are two doors: `/Page` from the text, which opens a child draft, and `s` in the explorer on a selected note. Either way, the file does not exist until you give it a name and save.

## Your turn

1. Create the note `Trip` and, with the cursor inside, insert `/Page`; call the sub-note `Beach packing` and save it with `ctrl+s`.
2. In the explorer, select `Trip`, press `s`, call the new note `Day 1` and save it.
