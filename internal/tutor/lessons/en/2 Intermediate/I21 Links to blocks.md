# I21 · Links to blocks

**You will learn:** to give a paragraph a name and link it from any note.

A block is a piece of a note with a name: you write `^booking` at the end of a paragraph and you can link it right away. `[[#^booking]]` is the block in this note and `[[Trip#^booking]]` the one in another. The `#` before the caret looks odd and has a reason: the hash separates the note from the part, as with headings, and the caret says the part is a block and not a heading. Without the `#` there would be nowhere to split note and part, which is why you never write just `[[^booking]]`.

## Your turn

1. At the end of a paragraph in this note write ` ^booking`, with the space in front.
2. In the same note write `[[#^booking]]`, put the cursor on the link and press `gd`.
3. Create the note `Trip` with a paragraph ending in `^booking` and link that block from here.
4. Type `[[#^` and look at the list of blocks, each one with its text beside it.
