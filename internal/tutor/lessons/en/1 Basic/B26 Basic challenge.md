# B26 · Basic challenge

**You will learn:** to use everything so far in a real shopping list.

This challenge checks nothing: there are no steps to pass, just a note to build. You pass it when you save the note with changes. If you get stuck, go back to the lesson that teaches that part; the links are at the end.

## Your turn

1. Create a new note with `space n`, save it as `Shopping list` and write a heading and three tasks.
2. Check off one task with `space o c` and remove the checkbox from another with `space o C`.
3. Add a link `[[Market]]` to the shopping note.
4. Switch to reading view with `space p` and review the list.
