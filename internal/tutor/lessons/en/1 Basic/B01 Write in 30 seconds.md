# B01 · Write in 30 seconds

**You will learn:** to get into the text with `i`, get out with `Esc`, save with `ctrl+s` and open a blank note with `space n`.

Misoku is a modal editor, like vim. In NORMAL every letter is a command; to type you have to enter INSERT with `i`. `Esc` takes you back to NORMAL and the cursor steps back one position, so an extra press breaks nothing: letters stop being typed and go back to being commands.

## Your turn

1. Go down to the practice area, press `i` and type `Today I start my travel journal`.
2. Press `Esc`: you leave INSERT, the cursor steps back and letters are commands again.
3. Press `ctrl+s` (or `space w`) to save the note.
4. Press `space n`: a new blank tab opens, with no name yet. It gets one the first time you save it.
