# B17 · Emphasis

**You will learn:** bold, italics, inline code and strikethrough.

Emphasis is written with marks around the text: two asterisks for bold, one for italics, backticks for code and two tildes for strikethrough. Inline code is drawn in a different typeface and the checker treats it separately: that is why your examples in code don't count as answers. The preview shows all four. Put each one on its own line so it reads well.
