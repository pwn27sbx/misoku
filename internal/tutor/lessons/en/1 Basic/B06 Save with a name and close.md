# B06 · Save with a name and close

**You will learn:** to save a copy with `:w name`, to see the dialog the first time you save a new note, and to close a tab with `space x`.

`:w` saves the note; with a name after it, `:w travel-list`, it saves a copy with that name in the vault and the tab takes that name. A note that has never been saved has no folder: when you save it, Misoku asks where it goes and suggests folders as you type the name. `space x` closes the tab and leaves you on the previous one.

## Your turn

1. Press `:` and run `w travel-list`: the copy appears in the vault and this tab is now called `travel-list`.
2. Press `space n` and `ctrl+s`: the dialog asks for a name and offers folders as you type. Close it with `Esc`.
3. Close the tab with `space x`: you are back on the copy `travel-list`.
