# B22 · Search inside the note

**You will learn:** to search with `/`, to repeat with `n` and `N`, and to read the search messages.

In NORMAL, `/` opens the search at the bottom; you type, `Enter` jumps to the first match, `n` goes to the next one and `N` to the previous one. Search is case-sensitive: `hotel` doesn't find `Hotel`. If there are no matches the bar turns red with `E486: Pattern not found`, and when you reach the end you will see `search hit BOTTOM, continuing at TOP`, which tells you it has started over. Search works the same in the editor and in the reading view.

## Your turn

1. Press `/`, type `hotel` and press `Enter`; do the same again in the reading view.
2. Press `n` for the next match and `N` for the previous one.
3. Search for `Hotel` with a capital letter and check that it no longer finds `hotel`.
4. Search for `zzz` and read the error; then search for `hotel` and press `n` past the last match to see the wrap-around message.
