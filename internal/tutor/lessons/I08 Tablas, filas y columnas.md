# I08 · Tablas: filas y columnas

**Vas a aprender:** a añadir y quitar filas y columnas con cuatro comandos.

Las tablas de Misoku no se editan a mano cuando crecen: hay comandos que saben dónde está el cursor y tocan la fila o la columna correcta. `:addrow` (o `:tr`) añade una fila debajo; `:addcol` (o `:tc`) añade una columna a la derecha; `:delrow` y `:delcol` las quitan. Todos respetan la alineación, así que no hay que recolocar los guiones a mano.

## Tu turno

1. Inserta `/Table`, pon el cursor dentro y ejecuta `:addrow` (o `:tr`).
2. Ejecuta `:addcol` (o `:tc`): aparece una columna nueva.
3. Ejecuta `:delrow`: la tabla pierde una fila.
4. Ejecuta `:delcol`: cada fila pierde una celda.
