# I23 · Enlaces Markdown y web

**Vas a aprender:** a enlazar notas y páginas web sin la sintaxis de doble corchete.

No todo enlace es un `[[…]]`. El Markdown clásico escribe el texto entre corchetes y la ruta entre paréntesis: `[mi nota](Viaje.md)`. Ese enlace apunta a un archivo, así que la ruta tiene que existir. Para la web hay dos formas: `[documentación](https://example.com)` y `<https://example.com>`, la segunda cuando lo que se lee es la propia dirección. Con el cursor en un enlace, `space o ]` salta al siguiente y `space o [` al anterior.

Prepara la nota `Viaje`.

## Tu turno

1. Inserta `/Enlace a página` y elige `Viaje`.
2. Escribe a mano `[mi nota](Viaje.md)`.
3. Escribe `[documentación](https://example.com)` y `<https://example.com>`.
4. Con el cursor en un enlace, salta al siguiente con `space o ]` y al anterior con `space o [`.
