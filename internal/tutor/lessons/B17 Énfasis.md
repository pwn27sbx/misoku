# B17 · Énfasis

**Vas a aprender:** negrita, cursiva, código en línea y tachado.

El énfasis se escribe con marcas alrededor: dos asteriscos para negrita, uno para cursiva, acentos graves para código y dos tildes para tachado. El código en línea se dibuja con otra tipografía y el corrector lo trata aparte: por eso tus ejemplos en código no cuentan como respuesta. En el preview se ven los cuatro. Pon cada forma en su propia línea para que se lea bien.

## Tu turno

1. Escribe `**reservar hotel**` en una línea nueva.
2. Escribe `*playa*` en otra línea.
3. Escribe el código `misoku`, con acentos graves alrededor.
4. Escribe `~~cancelado~~` en otra línea.
